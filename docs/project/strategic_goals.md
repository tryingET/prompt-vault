# Strategic Goals

These goals replace the older generic roadmap that over-weighted speculative platform expansion and under-weighted the repo's current real job.

## Active strategic goal

### SG1 — Keep Prompt Vault the canonical governed prompt-authoring substrate
- **Why now:** schema v9, governed vocabulary, company visibility, and prompt-authoring boundary notes are already live; the main risk is drift back into stale docs, duplicate ownership, or prompt bodies leaking into the wrong surfaces.
- **Success signal:** repo docs, tests, handoffs, and reusable procedures all reinforce the same truth: Prompt Vault owns prompt bodies + governed authoring contracts, while runtime consumers read that contract instead of re-owning it.
- **Eisenhower-3D:** importance `5`, urgency `5`, difficulty `3`

## Next strategic goal

### SG2 — Deepen privacy-safe evidence and downstream usability without collapsing boundaries
- **Why next:** once the source-of-truth layer is kept clean, the highest-value next work is aggregate-first quality/evidence reporting and better downstream consumption of the governed contract.
- **Success signal:** operators can learn more from quality/analytics surfaces and downstream integrations without widening raw private-output exposure or blurring owner boundaries.
- **Eisenhower-3D:** importance `5`, urgency `4`, difficulty `4`

## Not current strategic goals

These are intentionally **not** top strategic goals right now, even if they may matter later:
- multi-tenant external deployments
- broad dashboard productization
- generic SaaS/web-UI expansion

They are lower-priority than keeping the current governed substrate truthful and useful.
